# Foto bez přechodů

Jednoduchý Android prohlížeč fotografií zaměřený na okamžité přepínání bez animací, prolínání a černých záblesků.

## Funkce

- ruční prohlížení fotografií bez přechodových efektů,
- slideshow s intervalem od 0,1 sekundy do 24 hodin,
- stará fotografie zůstává zobrazená, dokud není nová připravená,
- přednačítání následujících fotografií,
- výběr složky v telefonu, na SD kartě nebo USB úložišti,
- procházení podsložek,
- opakování a náhodné pořadí,
- režim celého obrázku nebo vyplnění obrazovky,
- displej během používání nezhasíná,
- funguje bez internetu a bez registrace.

## Ovládání

1. Klepněte na **Složka** a vyberte složku s fotografiemi.
2. Tlačítky ◀ a ▶ přepínejte fotografie ručně.
3. V **Nastavení** zadejte interval, například `0,1` sekundy.
4. Tlačítkem **Spustit** zapněte slideshow.
5. Klepnutím do fotografie zobrazíte nebo skryjete ovládání.
6. Tažením vlevo nebo vpravo přepnete fotografii bez animace.

## Stažení APK z GitHubu

1. Otevřete záložku **Actions**.
2. Vyberte workflow **Build Android APK**.
3. Otevřete poslední úspěšný běh.
4. Dole v části **Artifacts** stáhněte `Foto-bez-prechodu-v1.0.0`.
5. ZIP rozbalte a do telefonu nainstalujte soubor `FotoBezPrechodu-v1.0.0.apk`.

Workflow se spustí automaticky po každé změně na větvi `main`. Lze jej spustit také ručně přes **Run workflow**.

## Technické údaje

- minimální Android: 8.0 (API 26),
- cílový Android: API 35,
- application ID: `cz.fotobezprechodu`,
- verze: 1.0.0.
